How it's calculated: each category's items count equally (score ÷ out of), with the lowest ones dropped if you set a drop count. Current uses real marks only and is scaled to the work graded so far. Locked in is how many of the 100 course points you already have. What-if adds your what-if rows. The course pass line is 50%. If a course has the exam rule on and your weighted exam average is under 50%, the final is capped at that exam average, which is a common Waterloo Engineering syllabus rule.
